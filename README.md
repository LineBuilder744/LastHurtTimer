This is a small client mod for minecraft 1.21.11 fabric (fabric version 0.19.3+) that adds a timer that shows the time that has passed since you last got hit. Especially useful for woolbattle players to check if you can void without getting killed. Soon i will make it for newer versions.

Default settings: position - left top corner, target timer - 10 seconds.

you can change the position or the target timer by these commands:

/lasthurttimer setpos x y - setting the position of your timer on the screen
/lasthurttimer setTicksToWait ticks - sets the target time for timer (default - 200 ticks or 10 seconds)
